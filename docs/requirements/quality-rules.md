# 一期质量指标与评分规则

- 规则状态：评审稿 v0.1
- 原则：固定标准、版本绑定、真实执行、自动与人工结果分离、只检测不修改正式数据。

## 1. 综合评分

综合得分为八个维度得分的加权和，所有维度取 0–100：

| Dimension | Weight | Minimum checks |
| --- | ---: | --- |
| 完整性 completeness | 18% | 文件/记录/必填字段缺失率、解析覆盖率 |
| 唯一性 uniqueness | 10% | 主键重复、完全重复、近似重复提示 |
| 规范性 conformance | 12% | 格式、编码、类型、值域、命名规范 |
| 一致性 consistency | 14% | 跨字段/跨文件逻辑、申报与实际一致性 |
| 可用性 usability | 12% | 可读、可解析、元数据覆盖、样例可用 |
| 标注质量 label_quality | 12% | 标注缺失、一致性、类别合法性；无标注数据按适用性重新归一权重 |
| 隐私残留 privacy_residual | 12% | PII/PHI 风险密度、严重度和复核结论 |
| 分布与代表性 representation | 10% | 类别/癌种/性别/年龄等分布、极端偏斜、覆盖提示 |

`overall = Σ(dimension_score × applicable_weight) / Σ(applicable_weight)`，四舍五入到两位。任何不适用维度必须由标准版本显式声明，不能由执行时临时删除。

## 2. 等级与上架门槛

- A：`score ≥ 95`
- B：`90 ≤ score < 95`
- C：`85 ≤ score < 90`
- D：`70 ≤ score < 85`
- E：`score < 70`

上架必须同时满足：综合分 ≥ 85；所有适用维度 ≥ 70；隐私残留 ≥ 90；不存在未关闭的 `CRITICAL/HIGH` 问题；准入最终结论为通过；人工复核已完成。

以下为硬失败，不因综合分抵消：恶意文件检测确认命中、文件哈希不一致、无法解压/读取、关键申报与实际版本不一致、确认存在严重未脱敏 PHI/PII、无法证明来源/授权、质量执行未完整完成。

## 3. 预置标准

### 3.1 结构化癌症数据 `CANCER_TABULAR_V1`

CSV/Excel/JSON 表格化数据；检查患者/样本伪标识、癌种编码、诊断/分期、日期顺序、数值范围、主外键、缺失与重复、类别分布、敏感标识残留。默认任何直接身份证号、手机号、住址、住院号等高置信命中进入人工复核。

### 3.2 医学文本 `MEDICAL_TEXT_V1`

检查编码、空文本、过短/重复、异常字符、语言、段落可读性、元数据覆盖和中文医疗 PII/PHI。Presidio 自定义识别器覆盖姓名、身份证、手机号、地址、住院/门诊/病案号、医院、科室和医生信息；识别结果只作风险提示。

### 3.3 医学影像基础 `MEDICAL_IMAGE_BASIC_V1`

检查文件可解码、尺寸/位深、损坏、重复、基础 DICOM 标签风险、影像内文字 OCR 风险、元数据与文件数量一致性。不进行诊断正确性或深度 AI 临床评价。

## 4. 结果模型

每个指标保存 `metric_code`、规则/算子版本、参数、输入范围、自动值、人工值、采用值、样本量、问题数、得分、开始/结束时间和执行日志引用。报告必须展示适用标准、排除项、抽样方法和限制，禁止将风险提示写成法定合规认证。

## 5. 整改复测

整改清单逐项记录问题、位置、严重度、建议、责任方和状态。供应商不能在平台直接修改正式文件，必须提交新接入批次或新版本。复测沿用原标准版本；若需升级标准，必须并列生成新任务并解释不可直接对比的原因。
