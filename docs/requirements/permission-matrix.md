## 数据范围规则

1. `SUPPLIER` 必须同时满足用户属于供应商、供应商为 ACTIVE、资源 `supplier_id` 匹配。
2. `DEMANDER` 只能访问 `demander_id = current_user` 的订单、合同、授权和交付。
3. 测评/复核人员只能查看 Flowable/平台显式分配且未撤销的任务对象；受限样本查看单独审计。
4. `ADMIN` 不自动获得原始数据文件内容权限；原始内容仍需任务或调查授权。
5. 对象权限在业务服务内校验；网关角色校验不能替代对象级校验。
6. 服务账号按受众和用途拆分，禁止复用管理员账号或授予交互式登录。
