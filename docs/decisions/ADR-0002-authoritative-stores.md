# ADR-0002: 明确系统权威数据边界

- 状态：已接受
- 日期：2026-09-02

## 决策

- PostgreSQL `platform_ops`：供应商、登记、上架、订单、合同、授权、交付与审计的业务权威。
- Dataverse：数据集文件、文件清单和数据集版本的权威。
- OpenMetadata：元数据、标签、分类、血缘、质量标准及质量结果索引的权威。
- 质量服务：检测过程、原始检测结果和问题样本的权威。
- Flowable：流程实例、人工任务和审批轨迹的权威。
- 身份系统：用户身份、启停状态和基础角色的权威。
- MinIO：对象实体；对象归属与业务语义由 Dataverse/业务库引用。

系统间只通过稳定业务 ID、API 和事件同步，不直接写入其他系统数据库。
